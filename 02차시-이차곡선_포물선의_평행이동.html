1. 포물선의 평행이동과 구성 요소의 이동

교과서 p.14
📌 포물선의 평행이동 공식

기본형 포물선 $y^2=4px$를 $x$축 방향으로 $m$만큼, $y$축 방향으로 $n$만큼 평행이동한 식:

$(y - n)^2 = 4p(x - m)$
기본형 ($y^2=4px$)
  • • 초점: $(p, 0)$
  • • 준선: $x = -p$
  • • 꼭짓점: $(0, 0)$, 축: $y = 0$
평행이동 ($(y-n)^2=4p(x-m)$)
  • • 초점: $\mathbf{(p + m, n)}$
  • • 준선: $\mathbf{x = -p + m}$
  • • 꼭짓점: $\mathbf{(m, n)}$, 축: $\mathbf{y = n}$
인터랙티브 변형

2. 포물선의 일반형을 표준형으로 변형하기

교과서 p.15
🔍 [변형 과정] 일반형 $y^2 - 4y - 8x + 12 = 0$의 표준형 변환
1. $y$에 대한 이차식을 좌변에, 나머지 항을 우변으로 이항한다:
  $y^2 - 4y = $ $8x - 12$
2. 좌변을 완전제곱식으로 만들기 위해 양변에 $4$를 더한다:
  $y^2 - 4y + 4 = 8x - 12 + 4 \implies (y - 2)^2 = $ $8x - 8$
3. 우변을 $x$의 계수로 묶어 표준형으로 정리한다:
  $(y - 2)^2 = $ $8(x - 1)$ $= 4(2)(x - 1)$
4. 분석: 기본형 $y^2=8x$ ($p=2$)를 $x$축으로 $1$, $y$축으로 $2$만큼 이동!
  꼭짓점: $\mathbf{(1, 2)}$, 초점: $\mathbf{(3, 2)}$, 준선: $\mathbf{x = -1}$

3. 초점과 준선이 주어진 평행이동 포물선

올림포스 01강 p.8 #002
EBS 올림포스 01강 002번 문항코드: 26449-0002
초점의 좌표가 $(-3, 3)$이고 준선의 방정식이 $y = -1$인 포물선이 $y$축과 만나는 점의 $y$좌표가 $k$일 때, $16k$의 값을 구하시오.
Step 1
초점이 $(-3, 3)$이고 준선이 $y = -1$이므로 꼭짓점은 두 좌표의 중점인 $\left(-3, \frac{3 + (-1)}{2}\right) = (-3, 1)$입니다.
Step 2
초점에서 꼭짓점까지의 거리 $p = 3 - 1 = 2$이므로, 기본형 $x^2 = 8y$를 $x$축으로 $-3$, $y$축으로 $1$만큼 평행이동한 식:
$(x + 3)^2 = 8(y - 1)$
Step 3
$y$축 교점($x = 0$) 대입: $(0+3)^2 = 8(k-1) \implies 9 = 8k - 8 \implies k = \frac{17}{8}$
따라서 $16k = 16 \times \frac{17}{8} = \mathbf{34}$
정답: $\mathbf{34}$
✍ 판서 공간

4. 포물선의 일반형 계수 결정

올림포스 01강 p.11 #004
EBS 올림포스 01강 004번 문항코드: 26449-0010
초점의 좌표가 $(2, -3)$이고 준선의 방정식이 $x = -4$인 포물선의 방정식이 $y^2 + ax + by + c = 0$이다. 세 상수 $a, b, c$에 대하여 $a + b + c$의 값은?
① -9
② -7
③ -5
④ -3
⑤ -1
Step 1
초점 $(2, -3)$과 준선 $x = -4$의 꼭짓점은 $\left(\frac{2+(-4)}{2}, -3\right) = (-1, -3)$입니다.
초점까지의 거리 $p = 2 - (-1) = 3$이므로 $4p = 12$입니다.
Step 2
포물선의 방정식은 $(y + 3)^2 = 12(x + 1) \implies y^2 + 6y + 9 = 12x + 12$
전개하여 정리하면 $y^2 - 12x + 6y - 3 = 0$
Step 3
$a = -12, b = 6, c = -3 \implies a + b + c = -12 + 6 - 3 = \mathbf{-9}$
정답: $\mathbf{①\\ -9}$
✍ 판서 공간

5. 축에 접하는 포물선과 판별식 활용

올림포스 01강 p.11 #005
EBS 올림포스 01강 005번 문항코드: 26449-0011 (축에 접하는 조건)
포물선 $x^2 - 6x - 8y + k = 0$이 $x$축에 접할 때, 이 포물선의 초점의 좌표는 $(a, b)$이다. $k + a + b$의 값은? (단, $k$는 상수)
① 11
② 12
③ 13
④ 14
⑤ 15
Step 1
$x$축에 접하므로 $y = 0$을 대입한 $x^2 - 6x + k = 0$이 중근을 가집니다.
$\frac{D}{4} = 9 - k = 0 \implies \mathbf{k = 9}$
Step 2
방정식에 $k = 9$ 대입: $(x - 3)^2 = 8y = 4(2)y$
이는 $x^2 = 8y$ (초점 $(0, 2)$)를 $x$축 방향으로 $3$만큼 이동한 것입니다.
Step 3
초점의 좌표는 $(0 + 3, 2) = (3, 2) \implies a = 3, b = 2$
따라서 $k + a + b = 9 + 3 + 2 = \mathbf{14}$
정답: $\mathbf{④\\ 14}$
✍ 판서 공간

6. 평행이동 포물선의 대칭성과 선분 비

올림포스 01강 p.11 #006
EBS 올림포스 01강 006번 문항코드: 26449-0012 (도형 대칭성 심화)
두 양수 $a, b$에 대하여 초점이 $F$인 포물선 $(y - b)^2 = a(x - 2)$가 $x$축과 만나는 점을 $A$라 하자. 점 $A$를 지나고 $x$축에 수직인 직선이 점 $F$를 지날 때, 이 직선이 포물선과 만나는 점 중 $A$가 아닌 점을 $B$라 하자. $\overline{AB} = 2\overline{OA}$일 때, $a + b$의 값을 구하시오. (단, $O$는 원점)
Step 1
$(y - b)^2 = a(x - 2)$는 $y^2 = ax$를 $x$축으로 $2$, $y$축으로 $b$만큼 평행이동한 포물선입니다.
초점은 $F\left(\frac{a}{4} + 2, b\right)$, 준선은 $x = -\frac{a}{4} + 2$입니다.
Step 2
직선 $AB$는 $x$축에 수직이고 $F$를 지나므로 $A$와 $B$의 $x$좌표는 모두 초점의 $x$좌표인 $\frac{a}{4} + 2$입니다.
포물선의 축 $y = b$에 대하여 점 $A\left(\frac{a}{4}+2, 0\right)$와 $B$는 대칭이므로 $\overline{AB} = 2b = 2\overline{AF}$
Step 3
주어진 조건 $\overline{AB} = 2\overline{OA}$에서 $\overline{AF} = b = \overline{OA} = \frac{a}{4} + 2$
준선이 $y$축($x=0$)이어야 하므로 $-\frac{a}{4} + 2 = 0 \implies \mathbf{a = 8}, \mathbf{b = 4}$
$\therefore a + b = 8 + 4 = \mathbf{12}$
정답: $\mathbf{12}$
✍ 판서 공간

7. 포물선과 정삼각형의 기하 결합

올림포스 01강 p.13 #011
EBS 올림포스 01강 011번 문항코드: 26449-0017 (수능 기출 변형)
포물선 $(y - 2)^2 = 8(x + 1)$ 위의 제1사분면에 있는 점 $P$와 초점 $F$, 준선 위의 점 $H$에 대하여 삼각형 $PFH$가 정삼각형일 때, 점 $P$의 $x$좌표를 구하시오.
Step 1
$p = 2$이므로 초점 $F$는 $(-1 + 2, 2) = (1, 2)$, 준선은 $x = -1 - 2 = -3$입니다.
Step 2
점 $P$의 좌표를 $(x_1, y_1)$이라 하면 준선까지의 거리 $\overline{PH} = x_1 - (-3) = x_1 + 3$
포물선의 정의에 의해 $\overline{PF} = \overline{PH} = x_1 + 3$입니다.
Step 3
정삼각형의 한 변의 길이가 $x_1 + 3$이고 점 $P$에서 준선 $x=-3$에 내린 수선과 축이 이루는 각은 $30^\circ$입니다.
삼각비 적용: $x_1 + 3 = 2\sqrt{3} + 3 \implies \mathbf{x_1 = 3}$
정답: $\mathbf{x = 3}$
✍ 판서 공간

갈릴레이의 포사체 운동 & 금문교(현수교)의 포물선
물리학의 발견 & 토목 공학의 경이

17세기 이탈리아의 과학자 갈릴레오 갈릴레이(Galileo Galilei)는 중력장에서 던져진 물체가 수평 등속 운동과 수직 등가속도 운동의 합성으로 인해 완벽한 포물선(Parabola) 궤적을 그린다는 사실을 수학적으로 증명했습니다.

또한 미국 샌프란시스코의 금문교(Golden Gate Bridge) 같은 현수교는 다리 상판의 무게가 수직 케이블을 통해 주 케이블에 균일하게 전달될 때, 주 케이블이 그리는 곡선이 수학적으로 정확히 포물선이 됩니다.

포물선 케이블은 엄청난 하중의 장력을 두 주탑으로 균일하게 분산시켜 다리가 무너지지 않고 버틸 수 있게 하는 핵심 공학적 원리입니다.

🏗️ 건축/공학적 의의: 장대 교량(현수교)의 주 케이블 장력 분산 및 로켓/미사일 탄도 궤적 계산
